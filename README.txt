順業肥料資材行 — 張育慈 個人品牌網頁
=====================================

【上傳方式】
把 index.html 和 assets 資料夾「一起」上傳到網站的根目錄，
兩者必須維持同一層、且資料夾名稱不要改成別的名字。

上傳後的網址結構應該長這樣：
  你的網域/index.html
  你的網域/assets/yuci-portrait.jpg
  ...

【檔案說明】
  index.html                  網頁本體（樣式與程式都已內含，不需其他檔案）
  assets/xizhou-plain.jpg     首頁背景：溪州平原晨光
  assets/yuci-portrait.jpg    張育慈形象照
  assets/warehouse-stock.jpg  庫存實景
  assets/pellet-hand.jpg      顆粒有機肥
  assets/field-apply.jpg      田間施用
  assets/og-card.jpg          分享到 LINE / FB 時顯示的縮圖

【還需要補的內容】
  1. 電話與 LINE：
     用文字編輯器開啟 index.html，搜尋「請提供後補上」，
     把那一整段 <span class="tbd">請提供後補上</span>
     換成電話號碼即可，例如：04-1234-5678
  2. 若之後有正式網域，建議把 index.html 裡的
     og:image 改成完整網址，分享縮圖才會正常顯示。

【注意】
  網頁使用 Google Fonts 線上字型（思源宋體／黑體），
  需要能連上網路才會顯示最佳字型；離線時會自動改用系統字型。
